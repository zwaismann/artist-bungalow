# Document vault

Place registration and email PDF backups here. The `/business` book links to these filenames.

Protected by the same password gate as `/business` (`BUSINESS_BOOK_PASSWORD`).

## Expected files (add in a follow-up; do not commit empty binaries)

| File | What it is |
| --- | --- |
| `authority-to-operate.pdf` | 2026-09-08 Authority to Operate (XSTR-25-0107). One-time / no valid date. |
| `rho-compliance-registration-application.pdf` | Filled RHO Compliance Registration Application (Sep 2026) |
| `2026-09-03-outbound-application-email.pdf` | Sep 3 outbound application email print |
| `2025-12-payment-receipt-and-first-ato.pdf` | Dec 2025 email extracts: $15 RHO payment receipt (2025-12-11) and first Authority to Operate (2025-12-22) |

After adding a PDF, redeploy so `/business#vault` can download it.

Do not store lockbox codes, door codes, Wi-Fi passwords, or guest PII in this folder.
