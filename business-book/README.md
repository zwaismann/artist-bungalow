# Document vault

Place registration and email PDF backups here. The `/business` book links to these filenames.

Protected by the same password gate as `/business` (`BUSINESS_BOOK_PASSWORD`).

## Expected files (add in a follow-up; do not commit empty binaries)

| File | What it is |
| --- | --- |
| `authority-to-operate.pdf` | LAPD Authority to Operate letter (issued 2026-09-08) |
| `rho-compliance-registration-application.pdf` | Filled RHO Compliance Registration Application |
| `2026-09-03-outbound-application-email.pdf` | 3 Sep outbound application email print |

After adding a PDF, redeploy so `/business#vault` can download it.

Do not store lockbox codes, door codes, Wi-Fi passwords, or guest PII in this folder.
